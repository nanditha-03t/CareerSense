CareerMatch – Campus Placement & Skill Gap Analysis Platform

Comprehensive Engineering Placement Intelligence & Readiness System

Batch-B | Project Review | Team: [Team No]

1. Problem Statement

Engineering students face placement rejections due to lack of visibility into company-specific skill requirements, unverified job portals, and absence of actionable skill gap analysis. CareerMatch automates skill evaluation against verified campus drives to pinpoint missing competencies and guide structured preparation.

3. Modules Included in the Project

  • Auth & RBAC: Secure Student & Placement Officer portals (bcrypt + JWT).
  • Academic Profile & Resume: Dynamic completion ($0–100\%$) with CGPA validation and PDF resume manager.
  • Skill Matching Engine: Real-time intersection of student skills vs. job requirements for accurate % fit.
  • Skill Gap & Recommendation: Priority classification (High/Medium/Low) based on market demand.
  • Job Board & Eligibility: Cut-off checker (CGPA eligible/unknown) with direct application links.
  • Preparation & Application Tracker: Domain readiness (DSA/Core CS) & placement pipeline tracker.
  • Placement Admin Portal: Officer dashboard for posting drives, reviewing resumes, and syncing jobs.

2. Technology Stack & Dataset / Sources

  • Frontend: React 18, Vite, Tailwind CSS, Lucide Icons
  • Backend: Node.js, Express.js, JWT, bcryptjs, Multer
  • Database: MongoDB via Mongoose (Users, Profiles, Skills, Jobs, Applications)
  • Data Sources / APIs: Remotive Open Public API (live tech feed) + Verified Campus Drives (TCS, Infosys, Accenture, Wipro, Amazon). No API key required.
  • Tools: Git, GitHub, Postman, Vite Build Tool
